# DEMO SCRIPT

About 6 minutes. Devices: **Laptop** on the projector (Cafe portal, second tab Admin), **Phone A** buyer (permanent code), **Phone B** runner (permanent code). Optional **Phone C** for a panel member with a temporary code.

## Before the presentation
1. Admin › Demo › Reset all data, then Seed demo data.
2. Phone A: log in as `AU2340101` Riya, wallet ₹300, default building GICT.
3. Phone B: log in as `AU2340102` Aarav, wallet ₹120.
4. Laptop: Cafe portal open, sound on. Admin › Codes ready in a second tab with one unused temp code shown big.
5. Put Admin › Users in a third tab to show wallets live.

## Story
1. **Problem (30 s).** "The break is 10 minutes. UC to AMSOM and back with a queue doesn't fit."
2. **Order (60 s).** Phone A: Home → Cafe Delice → Cold Coffee + Chilli Garlic Cheese Sandwich → Checkout → Deliver to GICT → As soon as possible → Pay ₹185. Show the 4-digit code and the promised time.
3. **Cafe (45 s).** Laptop: the order pops into New. Accept → Start preparing → Mark ready → show the bag slip QR.
4. **Runner (60 s).** Phone B: Scan → scan the slip on the laptop screen → "You earn ₹5" → Accept. Laptop card moves to Out for delivery with Aarav's name. Phone A Updates: "Picked up by runner buddy Aarav."
5. **Handover (30 s).** Phone A shows the code, Phone B enters it. Delivered. Phone B wallet +₹5, show the ledger.
6. **Vending (45 s).** Phone A: Vending → Paper Boat Aamras + Too Yumm Karare → Pick up → pay ₹45 → Laptop kiosk → enter code → slots dispense.
7. **Failure (60 s).** About 7 minutes before this step, Admin › Demo › "Create late-test order" (buyer Riya, runner Aarav). By now it is past its promised time: show it amber, then red when grace ends. Riya refunded, Aarav debited, red alert on the cafe desk. "Nobody has to chase it; the system decides who pays."
8. **Access (20 s).** Hand Phone C or the panel a temp code from Admin; show that it burns and a new one appears.

## If something breaks
Camera won't scan → use "Type order ID instead". Wi-Fi drops → phone hotspot for the laptop. Data looks wrong → Admin › Reset + Seed takes 10 seconds.
