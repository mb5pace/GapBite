# QuickX — by Team Gapbite

**QuickX** is a campus food-ordering platform built around the idea of solving the problem of *spaces between classes*. It allows students to pre-order food from university campus cafes and vending machines, collect orders using a pickup code, or request peer-runner delivery to their campus blocks. This version is a frontend prototype powered by mock data, without account login or a live payment backend.

**Current version:** `1.0.0`

**Live application:** https://quickx-gapbite.vercel.app

## Run locally

You need Node.js and npm installed.

1. Clone the repository.
2. Open the project directory.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open http://localhost:3000 in your browser.

## Item images

Item images are hotlinked using URLs defined in `data/itemImages.ts`. They are not stored as image files in this repository. Fallbacks are provided when an image is unavailable.
